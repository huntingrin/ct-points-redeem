# 类别规则

所有价格、面额、库存和资格以本次登录后的页面为准。以下是实测观察和判断规则，不是固定商品表。

## 话费

**入口**：`apps.telefen.com/jycalls/?channelCode=HGOKHD`（移动版话费兑换专区）。

**实测样本（2026-10-21，浙江，3 星）**：

| 面额 | 积分 |
|---|---|
| 10 元 | 1000 |
| 20 元 | 2000 |
| 30 元 | 3000 |
| 50 元 | 5000 |
| 100 元 | 10000 |

**规则**（页面原文要点）：

- 仅限电信积分充值，不支持现金；积分不足无法充值。
- 积分兑换话费仅在**当月 5–31 日**支持，其余时间不支持。
- **仅为登录号码充值**；副卡共享按各省规则，部分省份主卡不能共享。
- 积分直充话费不可转、不可退、不支持提现。
- 到账时间需登录 189.cn 营业厅查充值缴费记录/余额。
- 不开发票。

**必须区分**：

1. **直充话费**：一次扣积分，充到本机话费余额。本技能默认这一类。
2. **分期返还话费**：可能一次扣完积分、按多月返还；不能承诺立即到账。
3. **业务抵用金**：只限指定业务，不等同通用话费余额。

PC 商城搜索「话费」可能只返回「话费 X 元（固话专享）」，那是固话商品，不要当成本机移动话费。

## 流量

**入口**：商城首页搜索「流量」，或 `我可兑换` / 分类页。

**实测样本**：

- 账号 A（2026-10-20）：1GB/500 分、2GB/1000 分、6GB/3000 分、10GB/5000 分；另有 2GB+腾讯季卡 6400 分。
- 账号 B（2026-10-21，浙江 3 星）：搜索「流量」返回“没有找到哎”，当前账号目录无可兑流量；腾讯类只有 7400/7800 分组合，超出余额。

**结论**：流量商品**强依赖账号/省份/渠道**，不能因为一个账号有 2GB/1000 就承诺另一个账号也有。

**规则要点**（以 2GB 详情为例）：

- 当月有效、订购立即生效、限订购号码使用。
- 直接扣减有效积分，不退不换。
- 部分套餐、套餐迁转等特殊情形可能受限，选购时核对。

不要把组合里的流量有效期（当月）与影音会员有效期（如 93 天）混为一个期限。

## 影音与组合

**实测样本**：

- 腾讯视频 VIP 会员季卡：7800 分（纯会员）。
- 20 元话费 + 腾讯视频 VIP 季卡：7400 分。
- 5GB 流量 + 腾讯视频 VIP 季卡：7400 分（另一账号）。
- 2GB 流量 + 腾讯季卡：6400 分（旧账号样本）。

**规则要点**：

- 组合商品必须拆开列出每个组成部分，不能简写成“腾讯会员”。
- 腾讯季卡通常 93 天，按手机号及 QQ/微信绑定情况到账，不含电视端。
- 组合内流量仍按当月有效；整个组合不能都按 93 天解释。
- 第三方权益可能通过卡密、手机号直充或另填账号发放，以下单页说明为准。

## 语音

两个实测账号在同一商城检索「语音」均无结果（腾讯、流量搜索成功作为正向对照）。只证明这两个账号/渠道当前未找到，不外推全国。

没有当前在售 SKU、价格和有效期证据时，不写“可兑语音包”。

## 会员与其它（默认不做）

- 天翼超高清每月 N 选 1：需要已有优享会员、话费账单支付、当月成功扣费，按省/地市判断资格；用户已明确排除，本技能不默认办理。
- 天翼云盘云+联合会员：帮助文档提到积分兑换，但当前会员中心未见明确在售入口；用户已明确排除。
- 金豆签到、生日礼包：主要在 App，未验证独立网页闭环，不在本技能范围。
- 短信直兑：未核到全国现行统一指令与回执，不做无人值守承诺。

## 通用核对清单

下单前逐项确认：

- [ ] 商品完整名称和全部组成部分
- [ ] 所需积分、可用积分是否足够
- [ ] 现金补款是否为 0
- [ ] 有效期/到账时间
- [ ] 是否自动续订
- [ ] 是否限本机、是否限省份/套餐
- [ ] 是否可退、是否可转赠
- [ ] 到账账号（本机/第三方）

任何一项不明，先补读规则或让用户决定，不用旧样本补齐。
